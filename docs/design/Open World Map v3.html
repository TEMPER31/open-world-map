Open World Map · Design reference v3

Direction 2a, ready for hand-off. Everything opens in dark, and the "Dark mode" chip in any top bar (or Settings → Appearance) switches every screen to light. The field rows in the desktop Layers rail and the tiles in the mobile Layers sheet switch that screen's map between all six fields. The Layers rail can be minimised. Country geometry is real (Natural Earth); every field, event and name is synthetic sample data. Press play on any timeline (or click the track) to run −24 h → +7 days. All screens share one clock.
