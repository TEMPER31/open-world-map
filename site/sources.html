Sources & licences

Where every layer comes from

Every source the map uses, its licence or terms, the credit the map shows and when it loads. The map's credits strip lists the sources on screen at any moment.

This page matches the project's source register (docs/sources-register.md) row for row. A source is added there before it is added to the map. The code is MIT; data and imagery keep their own licences.

Events

Each feed loads while a matching event toggle is on, at most once per 10 minutes per source. Your browser keeps the results in memory. Opening a source link is a separate action.

The site's public Mapillary client token is added when the site is published and is never stored in the code. If Mapillary rejects it or its daily limit is reached, the layer says “unavailable right now” and nothing else is affected.

Not used

Esri World Imagery, MapTiler, Mapbox, Google Maps, Bing, CARTO, the OpenStreetMap tile service, NASA FIRMS and a direct JTWC feed are outside this build.
